# Day 1: Database Concepts #2

[Day contents](README.md) · [Week overview](../README.md)

## Learning Summary

Study table relationships, foreign-key referential actions, import/export and user-defined functions. Apply the concepts to relationship design and the Items and Orders challenge.

## Skills to Practice

- Choose suitable table relationships and referential actions.
- Move data into and out of PostgreSQL.
- Apply database functions and advanced querying concepts.

## Concepts Covered

- ON DELETE RESTRICT
- ON DELETE CASCADE
- Understanding PostgreSQL Referential Actions
- NO ACTION
- CASCADE
- SET NULL
- SET DEFAULT
- RESTRICT vs NO ACTION
- Best Practices
- Visual Representation of Foreign Key Actions
- One-To-One
- One-to-Many
