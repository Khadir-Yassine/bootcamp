# Day 1: Introduction To React

[Day contents](README.md) · [Week overview](../README.md)

## Learning Summary

Create a React application and work with JSX, components, props and list rendering. Apply Tailwind CSS and the Landing Page challenge to build a component-based interface.

## Skills to Practice

- Describe an interface as a component tree.
- Pass data through props.
- Render collections with map and stable keys.

- What are Props?

- Car.jsx
- App.jsx

- Using Destructuring
