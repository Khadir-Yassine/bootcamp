## Weekly Focus

Build React interfaces with JSX, props, state, effects, events and forms. Continue with routing, browser storage and data-driven mini projects.

## Day-by-Day Learning

### [Day 1: Introduction To React](day-01/summary.md)

Create a React application and work with JSX, components, props and list rendering. Apply Tailwind CSS and the Landing Page challenge to build a component-based interface.

### [Day 2: ESSEC Training Session](day-02/summary.md)

Scheduled activity with no published instructional content or project brief. The daily record documents the page’s availability.

### [Day 3: React components & State](day-03/summary.md)

Explore state updates, function and class components, lifecycle behavior, useState and useEffect. Exercises and the Voting App show how state changes drive rendering.

### [Day 4: Multiple Components & Events](day-04/summary.md)

Connect multiple components through event handlers and forms. Learn the purpose of error boundaries and distinguish rendering failures from errors handled with ordinary try/catch.

### [Day 5: Advanced React](day-05/summary.md)

Use React Router, keys and localStorage alongside data-driven interfaces and forms. The Users and Posts mini project combines navigation, component structure and application data.
