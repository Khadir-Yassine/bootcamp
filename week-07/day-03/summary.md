# Day 3: React components & State

[Day contents](README.md) · [Week overview](../README.md)

## Learning Summary

Explore state updates, function and class components, lifecycle behavior, useState and useEffect. Exercises and the Voting App show how state changes drive rendering.

## Skills to Practice

- Keep component state consistent with user interactions.
- Explain when an effect runs.
- Compare function components with class components.

- Introduction
- React definitions and render mechanisms
- Explanation
- Syntax
- Differences
