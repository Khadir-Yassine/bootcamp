### **Exercise 2 : Display the user input from a Form with React**

You will recreate this form:

**Empty Form**

![form](https://raw.githubusercontent.com/devtlv/studentsGitHub/master/JS/Week%208/Day4/Exercise%20XP%20Gold/form.png)

**Filled Form**

![input](https://raw.githubusercontent.com/devtlv/studentsGitHub/master/JS/Week%208/Day4/Exercise%20XP%20Gold/input.png)

1. Use the `state` to store the value of the inputs: first name, last name, phone, and email - you should make sure the inputs are correct before the submission.

2. When the form is submitted the form data should be displayed on the page, and the form should “disappear”. You can do this by calling a function (use a ternary operator that displays either the form, or the user’s data).

3. Add a reset button to reset all the values and display the form back.
