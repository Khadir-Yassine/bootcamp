### **Exercise 1: POST JSON Data**

**Instructions**

You will POST json Data from an form, fetch and console.log the result from your application with React JS: (use state to hold data to use it in your app)

1. In a new Class Component, create a form with 2 inputs and a button:
  
  - user
  - email
  - submit button

2. Use an `onChange` event handler on both inputs, that will change the user and the email values in the `state`.

3. When the submit button is clicked on, get the input values from the state, and use fetch to POST the stringified data to this [API](https://jsonplaceholder.typicode.com/users/). Finally, console log the data you just posted.

4. Import the component to the `App.js` file.
