# Week 5 Learning Summary

[Week contents](README.md) · [All weeks](../CONTENTS.md)

## Weekly Focus

Develop model-driven MongoDB applications with Mongoose, then study relational databases and PostgreSQL. Practice constraints, relationships, aggregation, joins and subqueries.

## Day-by-Day Learning

### [Day 1: Introduction to Mongoose](day-01/summary.md)

Connect Node.js to MongoDB through Mongoose, define schemas and models, and validate documents. Apply CRUD operations through a consistent model layer.

### [Day 2: Advanced Mongoose](day-02/summary.md)

Use instance methods, static methods, hooks and population to organize model behavior and relationships. Add filtering, pagination and consistent error handling.

### [Day 3: Real-World Project & Optimization](day-03/summary.md)

Organize a realistic project around user and product models, authentication-ready data and indexes. The capstone and final challenge connect folder structure, validation, performance and common mistakes.

### [Day 4: Introduction to Databases](day-04/summary.md)

Introduce relational database concepts and PostgreSQL through pgAdmin and the command line. Create and change tables and records with SQL, then apply the concepts in exercises and the Actors challenge.

### [Day 5: Database Concepts #1](day-05/summary.md)

Use aggregate functions, HAVING, UNION, foreign keys and joins to answer questions across related tables. Practice grouping results and combining data without unnecessary duplication.

### [Day 6: Remote Learning](day-06/summary.md)

Study queries nested inside other SQL queries and review Python file input/output. Open, read, write, append and close files while understanding the effect of each mode.
