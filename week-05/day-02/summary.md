## Learning Summary

Use instance methods, static methods, hooks and population to organize model behavior and relationships. Add filtering, pagination and consistent error handling.

## Skills to Practice

- Distinguish instance methods from static methods.
- Apply middleware hooks at appropriate lifecycle stages.
- Handle relationships and paginated query results.
