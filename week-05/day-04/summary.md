# Day 4: Introduction to Databases

[Day contents](README.md) · [Week overview](../README.md)

## Learning Summary

Introduce relational database concepts and PostgreSQL through pgAdmin and the command line. Create and change tables and records with SQL, then apply the concepts in exercises and the Actors challenge.

## Skills to Practice

- Distinguish tables, rows, columns and keys.
- Use SQL to read and modify stored data.
- Work with PostgreSQL tooling and table definitions.
