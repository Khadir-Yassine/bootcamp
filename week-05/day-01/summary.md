[Day contents](README.md) · [Week overview](../README.md)

## Learning Summary

Connect Node.js to MongoDB through Mongoose, define schemas and models, and validate documents. Apply CRUD operations through a consistent model layer.

## Skills to Practice

- Define schema fields and constraints.
- Connect the application to MongoDB.
- Create and query documents through models.
