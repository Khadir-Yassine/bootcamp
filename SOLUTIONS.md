## Getting started

1. Follow an activity's `solutions.md` rather than installing packages at the repository root.
2. For standalone browser examples, open their HTML file or serve the repository with `python -m http.server 8000`.
3. For Node and React projects, install dependencies in the documented project folder and follow its start command.
4. For Python programs, run the documented `.py` entry point. For SQL, use a disposable learning database and follow the stated schema/data setup.

API keys belong in your local configuration; use the supplied placeholders or example environment files. MongoDB and PostgreSQL examples require their stated database setup. Synthetic SQL fixtures and mocked API tests are labeled; they do not certify a live external service.
