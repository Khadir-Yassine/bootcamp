### **Exercise 1 : Outputs**

Predict the output of the following code snippets:

```javascript
>>> 3 <= 3 < 9

>>> 3 == 3 == 3

>>> bool(0)

>>> bool(5 == "5")

>>> bool(4 == 4) == bool("4" == "4")

>>> bool(bool(None))

x = (1 == True)
y = (1 == False)
a = True + 4
b = False + 10

print("x is", x)
print("y is", y)
print("a:", a)
print("b:", b)
```
