# Worked solutions

Run `python solution.py` from this folder. Source: [solution.py](solution.py). Python 3 and its standard library are sufficient. Interactive/demo options are explained below.

<a id="exercise-1"></a>

## 1. Print a first name

The executable file prints the name supplied through `--name`, defaulting to Yassine. No IDE installation is needed to run this completed source file.

<a id="exercise-2"></a>

## 2. Age in 24 years

The script creates my_age from the `--age` argument and prints my_age + 24. The default 20 is illustrative; pass your own age to practice the exercise.
