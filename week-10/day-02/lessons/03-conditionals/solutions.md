# Worked solutions

Run `python solution.py` from this folder. Source: [solution.py](solution.py). Python 3 and its standard library are sufficient. Interactive/demo options are explained below.

## 1. Short name

Ask for a name with `--interactive`; names with fewer than five characters produce **You have a short name :)**. Five is excluded by the strict less-than comparison.

## 2. FizzBuzz

Check divisibility by 15 before divisibility by 3 or 5. This makes 15 return FizzBuzz rather than stopping early at Fizz. 3 gives Fizz, 5 gives Buzz and ordinary values return their number. Input outside 1–100 is rejected.
