Run `python solution.py` from this folder. Source: [solution.py](solution.py). Python 3 and its standard library are sufficient. Interactive/demo options are explained below.

## 1. Formatting a greeting

Both the f-string and str.format versions print **Hello, Alice! You are 30 years old and live in New York.** The supplied values are stored as variables.

## 2. Years until 100

input returns text, so `years_until_100` explicitly converts the entered age with int before subtracting it from 100. For age 30 the result is **70 years**. Use `--interactive` for the input prompt.

[Original exercise](individual/02-exercise-2.md)

## 3. Age input prediction

The original program prints **You are [entered value] years old**. No numerical conversion is necessary when interpolating a string into a sentence. The default demonstration uses the example age 30; it is not a claim about the learner.
