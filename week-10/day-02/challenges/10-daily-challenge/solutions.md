# Worked solutions

Run `python solution.py` from this folder. Source: [solution.py](solution.py). Python 3 and its standard library are sufficient. Interactive/demo options are explained below.

<a id="exercise-1"></a>

## 1. Multiples

The requested list contains number × 1 through number × length. 7 and 5 produce **[7,14,21,28,35]**. Length zero returns an empty list; negative length raises ValueError. Run `--demo` for sample output or omit it for prompts.

<a id="exercise-2"></a>

## 2. Consecutive duplicate removal

Keep the first character and each later character that differs from its predecessor. ppoeemm becomes poem and wiiiinnnnd becomes wind. Nonadjacent repeated characters are preserved. Empty input produces an empty string.
