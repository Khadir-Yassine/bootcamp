# Week 10 Learning Summary

[Week contents](README.md) · [All weeks](../CONTENTS.md)

## Weekly Focus

Apply React in mini projects, then introduce Python data structures, functions and object-oriented programming. Extend classes with inheritance, properties, special methods and modules.

## Day-by-Day Learning

### [Day 1: Mini Project React](day-01/summary.md)

Apply React in Snap Shot, Random Quote Generator and Calculator projects. Translate interface requirements into components, state and displayed results.

### [Day 2: Introduction to Python Programming](day-02/summary.md)

Start Python with variables, sequences, lists, sets, tuples, conditionals and loops. Practice small algorithms and collection processing with Python syntax.

### [Day 3: Python Essentials](day-03/summary.md)

Work with dictionaries, functions, args, kwargs, lambda expressions and map/filter/reduce. Organize structured data and build flexible reusable transformations.

### [Day 4: Introduction to OOP](day-04/summary.md)

Introduce classes, objects and instance methods. Use examples and exercises to group state and behavior and distinguish a class definition from its instances.

### [Day 5: OOP Inheritance, Encapsulation, Polymorphism and Multiple Inheritance](day-05/summary.md)

Study inheritance, encapsulation, polymorphism, class/static methods, properties and dunder methods. Modules, exceptions and the Pagination challenge extend the ideas into reusable programs.
