# Worked solutions

Run `python solution.py` from this folder. Source: [solution.py](solution.py). Python 3 and its standard library are sufficient. Interactive/demo options are explained below.

## 1. Birthday lookup

A five-person example dictionary uses YYYY/MM/DD dates. The program welcomes the user, lists available names and formats the chosen person’s birthday. `--interactive` asks for the name.

## 3. Repeated-digit sum

Convert X to a string for repetition, then convert each of X, XX, XXX and XXXX back to integers and sum them. For X=3 the result is **3702**. Non-negative integer inputs are accepted.

[Original exercise](individual/03-exercise-3-sum.md)

## 4. Double dice

throw_dice returns 1–6. throw_until_doubles rolls two dice per round until they match and returns the number of rounds, not individual dice. dice_statistics calls it **100 times**, retains every result and prints total rounds and mean rounded to two decimals.

[Original exercise](individual/04-exercise-4-double-dice.md)
