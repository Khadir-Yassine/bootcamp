### **Exercise 2 : Custom List Class**

**Instructions**

1. Create a class called `MyList`, the class should receive a list of letters.

2. Add a method that returns the reversed list.

3. Add a method that returns the sorted list.

4. **Bonus** : Create a method that generates a second list with the same length as `mylist`. The list should be constructed with random numbers. *(use list comprehension)*.
