## 4. Zoo

Zoo starts with a name and empty animals. Add rejects duplicates; get prints all; sell removes only an existing animal. sort builds alphabetical first-letter groups, representing a single animal as a string and multiple animals as a list to match the prompt. get_groups refreshes and prints the grouping. new_york_zoo demonstrates every method.

[Original exercise](individual/04-exercise-4-afternoon-at-the-zoo.md)
