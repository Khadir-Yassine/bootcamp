# Day 4: Introduction to OOP

[Day contents](README.md) · [Week overview](../README.md)

## Learning Summary

Introduce classes, objects and instance methods. Use examples and exercises to group state and behavior and distinguish a class definition from its instances.

## Skills to Practice

- Create instances from a class.
- Define instance attributes and methods.
- Represent related behavior through an object model.

## Concepts Covered

- Introduction to OOP
- Object Oriented Programming
- I. Classes
- II. Objects (instances)
- III. Defining a class
- IV. Creating an object (instance)
- V. Attributes
- VI. The __init__ method
- Code Example of classes and objects
- Classes and Objects
- Instance methods
- Instance Methods
