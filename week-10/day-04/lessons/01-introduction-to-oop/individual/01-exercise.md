**Exercise**

- Analyse the code below. What will be the ouput ?

- Explain the goal of the `__init__()` method

```javascript
class Point():
    def __init__(self, x, y):
        self.x = x
        self.y = y

## create an instance of the class
p = Point(3,4)

## access the attributes
print("p.x is:", p.x)
print("p.y is:", p.y)
```
