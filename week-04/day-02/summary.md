# Day 2: Node.js Introduction

[Day contents](README.md) · [Week overview](../README.md)

## Learning Summary

Run JavaScript outside the browser, organize modules, and manage packages with NPM. Explore import/export, core modules and how Node.js executes application code.

## Skills to Practice

- Run a Node.js program and organize its files.
- Import and export reusable functionality.
- Install and manage project dependencies.

## Concepts Covered

- What is Node JS?
- Why Node JS?
- Installing Node JS
- Initializing Node JS in a folder
- How to install packages using npm install
- Check outdated packages
- Upgrade packages
- How to import and export using the module object in NodeJS
- Module object
- Exporting and importing modules
- Exporting other values
- How about exporting the exports as a single variable?
