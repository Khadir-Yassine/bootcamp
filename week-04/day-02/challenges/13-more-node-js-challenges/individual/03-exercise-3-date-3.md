### **Exercise 3: Date #3**

1. In a new file called `date.js`, write a function that returns today’s date and the amount of time left from now until the next holiday, additionally display what holiday that is. Export this function.
**Hint**: Start with hardcoding the datetime and name of the holiday.

2. In the file `script.js` display the result of the function created in `date.js`.
(Example: the next holiday is in 30 days and 12:03:45 hours)

3. **Bonus** : Try to find a node module to get the date of the holidays instead of hardcoding it.
