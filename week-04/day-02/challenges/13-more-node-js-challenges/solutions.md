# Reference solution

Date arithmetic subtracts timestamps in milliseconds. Minutes lived is floored to completed minutes; future/invalid births are rejected. The holiday example deliberately uses a small hardcoded calendar, as permitted by the assignment, rather than implying it is a complete national calendar.

## Files

- [`date.js`](solution/date.js)
- [`script.js`](solution/script.js)

## Run

From this activity's `solution` directory:

```sh
# No third-party dependencies needed.
node script.js
```

These are reference implementations. The original assignment is preserved in [README.md](README.md).
