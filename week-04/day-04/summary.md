# Day 4: MongoDB Fundamentals

[Day contents](README.md) · [Week overview](../README.md)

## Learning Summary

Understand MongoDB documents and collections, then practice create, read, update and delete operations. Use filters and operators to retrieve or modify selected records.

## Skills to Practice

- Represent data as documents in collections.
- Use CRUD commands with appropriate filters.
- Combine query operators to express conditions.
