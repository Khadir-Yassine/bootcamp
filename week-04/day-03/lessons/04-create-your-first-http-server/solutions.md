# Reference solution

The root route returns the required HTML heading; /menu returns the required JSON object and /unknown returns 404. Content-Type matches each response.

## Files

- [`simple-server.js`](solution/simple-server.js)

## Run

From this activity's `solution` directory:

```sh
# No third-party dependencies needed.
node simple-server.js
# Visit http://localhost:3000 and /menu
```
