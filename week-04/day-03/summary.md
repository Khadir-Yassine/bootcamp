# Day 3: Node.js Web Server

[Day contents](README.md) · [Week overview](../README.md)

## Learning Summary

Create HTTP servers and Express routes, accept route parameters and POST requests, and build CRUD APIs. Use Postman and request examples to inspect endpoint behavior.

## Skills to Practice

- Connect HTTP methods to endpoint responsibilities.
- Read request parameters and send suitable responses.
- Test API behavior and understand the event loop.
