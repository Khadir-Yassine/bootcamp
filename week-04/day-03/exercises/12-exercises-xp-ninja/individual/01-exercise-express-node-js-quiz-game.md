### **Exercise : Express Node.js Quiz Game**

**Instructions**

Create a simple quiz game using Express Node.js. In this exercise, you will build a web-based quiz application where users can answer multiple-choice questions and get immediate feedback on their answers.

**Requirements:**

1. Set up an Express server to serve your application.

2. Create a basic frontend using HTML, CSS, and JavaScript for the quiz interface.

3. Define a set of questions, each with multiple-choice answers and a correct answer.

4. Display one question at a time to the user.

5. Allow the user to select an answer and submit it.

6. Provide immediate feedback to the user about the correctness of their answer.

7. Keep track of the user’s score.

8. Display the final score at the end of the quiz.

**Advanced Features (Optional):**

- Implement a timer for each question.

- Add different levels of difficulty with varying question types (true/false, fill in the blank, etc.).

- Allow users to save their scores and view a leaderboard.

- Use a database to store questions and user data.

- Implement user authentication to track individual scores.
