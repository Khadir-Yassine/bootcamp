# Reference solution

Exercises 1–3 check HTTP status before reading JSON. The sun query uses limit 10 and offset 2. Exercise 4 prints `calling` immediately and `resolved` about two seconds later. Set your own `GIPHY_API_KEY` in the shell before running; no key is committed.

- [`app.js`](solution/app.js)

## Run

From this activity's `solution` directory:

```sh
# No third-party dependencies needed.
node app.js
```
