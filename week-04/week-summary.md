# Week 4 Learning Summary

[Week contents](README.md) · [All weeks](../CONTENTS.md)

## Weekly Focus

Progress from Fetch and async/await to server-side JavaScript, NPM, HTTP APIs and MongoDB. Connect application requests to persistent data and explore mini-project ideas.

## Day-by-Day Learning

### [Day 1: Fetch & Async/Await](day-01/summary.md)

Use Fetch and async/await to structure network operations and handle failures. Compare the syntax with promise chains and coordinate independent requests with Promise.all.

### [Day 2: Node.js Introduction](day-02/summary.md)

Run JavaScript outside the browser, organize modules, and manage packages with NPM. Explore import/export, core modules and how Node.js executes application code.

### [Day 3: Node.js Web Server](day-03/summary.md)

Create HTTP servers and Express routes, accept route parameters and POST requests, and build CRUD APIs. Use Postman and request examples to inspect endpoint behavior.

### [Day 4: MongoDB Fundamentals](day-04/summary.md)

Understand MongoDB documents and collections, then practice create, read, update and delete operations. Use filters and operators to retrieve or modify selected records.

### [Day 5: Advanced MongoDB & Data Modeling](day-05/summary.md)

Explore ObjectId, MongoDB data types, indexes and schema design. Compare embedded and referenced documents and consider how access patterns affect the model.

### [Day 6: Mini Projects](day-06/summary.md)

Review project ideas that combine Node.js with database-backed application behavior. Use the original requirements to choose a manageable scope and identify necessary data and operations.

### [Day 7: Mini Projects](day-07/summary.md)

Explore an additional open-ended set of project ideas. Select a practical scope and plan how Node.js and MongoDB features will support the application.
