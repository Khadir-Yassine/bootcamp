## Known limits and choices

| Case | What is included | What is unavailable or required |
| --- | --- | --- |
| Weeks 6 and 11 empty project pages | Explicit status beside each original page | Actual project requirements were not published |
| Week 8 Project X schedule | Week/day summaries and availability index | No actionable project brief in the archive |
| Partially visible or empty quizzes | Explanations for the visible questions only | Unseen questions; no platform submission made |
| Week 3 reflection exercises | Labeled illustrative English responses | Personal experiences must be supplied by the learner |
| Open-choice weekend projects | A permitted Todo Manager or Expense Ledger implementation | Alternative ideas are options, not additional mandatory projects |
| Empty extracted exercise headings | Actual published instructions in that page are answered | No invented question is attached to an empty heading |
| External API activities | Request, loading and error-handling code | Internet access and, where stated, a personal API key |
| Database activities | Scripts, models, APIs and setup instructions | A configured database; official DVD data for its exact results |
| React apps | Source in shared workspaces, with per-assignment component links | Hosted deployment is not configured |
| Solar-system moon bonus | One marker per moon in a dated NASA count snapshot | Only selected moons have names; other markers are numbered |

The solar-system bonus originally rendered only selected moons. It now creates the full number of markers in its documented snapshot and keeps large collections expandable. Counts are sourced in the [solution guide](week-01/day-03/challenges/11-daily-challenge-planets/solutions.md).

No missing solution-guide link was found for a published assignment or embedded lesson exercise. File coverage does not replace behavioral validation; checks actually completed are recorded in [VALIDATION.md](VALIDATION.md).
