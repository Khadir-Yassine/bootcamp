## Weekly Focus

Build a foundation in JavaScript values, control flow and functions, then connect that logic to DOM updates and browser events. Finish with interactive Coloring Game and Drumset projects.

## Day-by-Day Learning

### [Day 1: First Day](day-01/summary.md)

Scheduled activity with no published instructional content or project brief. The daily record documents the page’s availability.

### [Day 2: Introduction to Javascript](day-02/summary.md)

Understand variables, primitive values, comparisons, conditionals, loops, arrays and objects. Use the console to inspect values, predict program output and debug small algorithms.

### [Day 3: Functions & DOM introduction](day-03/summary.md)

Create functions with parameters and return values, then connect JavaScript logic to HTML through the DOM. Select elements, change content and attributes, and work with form properties.

### [Day 4: Learning DOM Events](day-04/summary.md)

Handle browser events, validate form input, and schedule work with setTimeout and setInterval. Use these tools to create pages that respond to clicks, typing and timed changes.

### [Day 5: Mini-Project Day](day-05/summary.md)

Combine DOM manipulation, events and JavaScript logic in the Coloring Game and Drumset projects. The existing JavaScript quiz review is retained as question material, with personal results removed.
