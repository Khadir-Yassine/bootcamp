# Day 2: Introduction to Javascript

[Day contents](README.md) · [Week overview](../README.md)

## Learning Summary

Understand variables, primitive values, comparisons, conditionals, loops, arrays and objects. Use the console to inspect values, predict program output and debug small algorithms.

## Skills to Practice

- Choose appropriate variable declarations and data types.
- Use branches and loops to express an algorithm.
- Read and update arrays and object properties.
