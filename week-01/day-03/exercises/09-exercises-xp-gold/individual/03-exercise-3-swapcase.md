### **Exercise 3 : SwapCase**

**Instructions**

Write a JavaScript function which takes a string as an argument and swaps the case of each character.
For example :

```javascript
if you input 'The Quick Brown Fox' 
the output should be 'tHE qUICK bROWN fOX'.
```
