## Exercises 1–4

- **Blank string:** trimming makes whitespace-only strings blank as well as the empty string.
- **Abbreviated name:** keep the first name and the last name's initial. `Robin Singh` becomes `Robin S.`; a single name stays unchanged.
- **Swap case:** convert each uppercase letter to lowercase and each lowercase letter to uppercase. Digits and punctuation remain unchanged.
- **Omnipresent value:** `every` requires every subarray to include the value. An empty main array returns true, following the usual all-elements convention.

## Exercise 5: Red Table

Open `index.html`. The page contains the required five-by-five table, and the JavaScript loops over its rows, setting cell `[i][i]` to a red background. Other cells are unchanged.
