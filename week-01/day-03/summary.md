# Day 3: Functions & DOM introduction

[Day contents](README.md) · [Week overview](../README.md)

## Learning Summary

Create functions with parameters and return values, then connect JavaScript logic to HTML through the DOM. Select elements, change content and attributes, and work with form properties.

## Skills to Practice

- Separate reusable logic into functions.
- Navigate the DOM tree and select elements.
- Update page content and read form values.

## Concepts Covered

- What is a function?
- Functions
- DOM Basics
- What is DOM (Document Object Model)
- Ways to Select Elements
- Finding HTML Elements
- Changing HTML Elements
- Adding and Deleting Elements
- What is DOM in JavaScript?
- Accessing DOM nodes
- Creating/Adding/Deleting DOM nodes
- Cache selectors
