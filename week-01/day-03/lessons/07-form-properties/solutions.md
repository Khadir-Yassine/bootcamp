## Run

## Solution

Read the original second option before inserting anything: its value is `university`. Append `Work`, prepend `Primary School`, then demonstrate selection through `value`, `selectedIndex` and the option's `selected` property. All three methods select College. The button reads the current selection when clicked, rather than retaining an old value.
