# Functions: Parameters and Return Values: Worked Solutions

[Lesson](README.md) · [Open browser demo](index.html) · [JavaScript](solutions.js)

## Run

Open `index.html` in a browser, or serve the repository with `python -m http.server 8000` and navigate to this folder.


## Exercise 1

For an illustrative age of 20, the mother is 40 and the father is 48. `parentAges(myAge)` logs both values, taking the father calculation from the mother's age rather than directly from `myAge`.

## Exercise 2

`motherAge(myAge)` returns the value without printing inside the function. The caller stores that return value in the outer scope and logs it. Run `node solutions.js` for the same examples in a terminal.
