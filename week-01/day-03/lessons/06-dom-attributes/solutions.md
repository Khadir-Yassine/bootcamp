# Read Attributes and Change Styles: Worked Solutions

[Lesson](README.md) · [Open browser demo](index.html) · [JavaScript](solutions.js)

## Run

Open `index.html` in a browser, or serve the repository with `python -m http.server 8000` and navigate to this folder.


## Exercise 1: Link Attributes

The five named variables read the literal attribute values with `getAttribute`. The displayed result contains the original URL, language, relationship, target and MIME type.

## Exercise 2: Paragraph Styling

Set the paragraph's `fontSize`, `fontFamily`, `color` and `fontWeight` through JavaScript. No replacement of the text or HTML is needed.
