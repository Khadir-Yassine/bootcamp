# Planets and Moons — Worked Solutions

[Instructions](README.md) · [Source](solutions.js) · [Browser app](index.html)

## Run

```sh
node solutions.js
```


## Implementation

Open `index.html`. JavaScript creates a div with class `planet` for each of the eight planet objects, assigns a distinct background color, and appends it under the supplied section. The page has a black background.

The bonus uses an array of objects containing moon-name arrays. Each listed moon becomes a separate `.moon` element beside its planet, avoiding overlapping absolute-positioned circles. The named moon lists are an explicitly **selected educational sample**, not current total counts for giant planets. Add further moon names to the data without changing the rendering algorithm.
