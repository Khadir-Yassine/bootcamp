# Day 4: Learning DOM Events

[Day contents](README.md) · [Week overview](../README.md)

## Learning Summary

Handle browser events, validate form input, and schedule work with setTimeout and setInterval. Use these tools to create pages that respond to clicks, typing and timed changes.

## Skills to Practice

- Register event handlers and work with event data.
- Read, validate and respond to user input.
- Implement timed interactions and simple animations.

## Concepts Covered

- Description :
- I. Two ways of writing Event handlers
- II. this keyword
- III. addEventListener(): multiple events on the same element
- IV. Event object
- V. Event Propagation
- onchange Event
- oninput Event
- event.preventDefault()
- What is form validation?
- Why do we need form validation?
- Different types of client/server-side validation
