# Delayed Sale Banner: Worked Solutions

[Lesson](README.md) · [Open browser demo](index.html) · [JavaScript](solutions.js)

## Run

Open `index.html` in a browser, or serve the repository with `python -m http.server 8000` and navigate to this folder.


## Exercise 1

The banner is initially hidden. A single timeout reveals it after a requested delay of 5000 milliseconds. The wording stays exactly as supplied. This exercise does not request a countdown or a checkout flow, so no extra timer is introduced.
