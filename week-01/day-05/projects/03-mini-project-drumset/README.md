### **Project Brief**

Create a drumset using HTML, CSS, JS.

**Goal of this Mini project**

This looks complex, but it’s pretty simple.

1. Get the clicked element, or key press.

2. Use it’s value to get the correct audio element.

3. Play the audio element.

## **Hints**

1. Focus on the JS. Get it working. Make it look pretty later.

2. Look up how to play audio in HTML and JS. (w3schools)

3. Add event listeners for keyboard and/or mouse clicks.

  - for keyboard events, you can get the key by looking at the property **keyCode** of the **event object**
  - for mouse click events, you can get the key by looking at the **this** object.
