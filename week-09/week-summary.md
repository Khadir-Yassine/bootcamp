# Week 9 Learning Summary

[Week contents](README.md) · [All weeks](../CONTENTS.md)

## Weekly Focus

Study advanced hooks, component boundaries, reusable component interfaces and state ownership. Combine the concepts in a complete mini application.

## Day-by-Day Learning

### [Day 1: React Advanced Hooks](day-01/summary.md)

Study useRef, useContext and useReducer for references, shared values and more structured state transitions. Apply them in the Herolo assignment and Enhanced Task Manager.

### [Day 2: Understanding Component Architecture](day-02/summary.md)

Break an application into components and identify parent-child relationships. Use the exercises to design a clear component hierarchy for an interface.

### [Day 3: Building Reusable Components](day-03/summary.md)

Build components with clear props and focused responsibilities. Practice reusable buttons, data passing and composing a small interface from reusable parts.

### [Day 4: Managing State and Interactions](day-04/summary.md)

Distinguish state from props and connect clicks and inputs to state changes. Counter, toggle and task-list exercises turn display components into interactive features.

### [Day 5: Assembling the Final Application](day-05/summary.md)

Combine components into a complete mini application and review folder structure, clean code and basic optimization. Refactor the project for clarity and reuse.
