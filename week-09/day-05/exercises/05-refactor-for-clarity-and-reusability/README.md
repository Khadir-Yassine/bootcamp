# Refactor for Clarity and Reusability

Course source: [Geeks Institute](https://www.geeks.institute/).
1. **The Goal:** Spot bad code and fix it.

2. **The Task:** Imagine you inherited some code from a previous student. They wrote three separate, massive functions: `CheckDobotConnection()`, `CheckTuyaConnection()`, and `CheckDatabaseConnection()`.

3. **Action:** Explain how you would refactor (rewrite) this into a single, clean function called `CheckSystemHealth(deviceName)` that can handle all three.
