# Combine Components into One Application

Course source: [Geeks Institute](https://www.geeks.institute/).
1. **The Goal:** Practice visualizing the final composition.

2. **The Task:** Sketch out the master `<App>` component for AutoBarista. Write out the "tree" showing how `<Header>`, `<Sidebar>`, `<DashboardLayout>`, `<HardwareStatusGrid>`, and `<OrderQueue>` all fit inside the master `<App>`.
