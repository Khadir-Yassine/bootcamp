# Pass Data Using Props

Course source: [Geeks Institute](https://www.geeks.institute/).
- **The Goal:** Practice the "Waterfall" data flow.

- **The Task:** Imagine a Parent component called `<RobotArmStatus>`. It knows that the arm's current temperature is `45°C` and its current task is `Moving to cup`.

- Write out how you would render two `<DataDisplay>` child components inside that Parent, passing the temperature to one, and the task to the other using Props.
