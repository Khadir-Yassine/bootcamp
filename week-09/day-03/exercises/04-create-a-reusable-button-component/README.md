# Create a Reusable Button Component

Course source: [Geeks Institute](https://www.geeks.institute/).
1. **The Goal:** Build the most flexible button possible.

2. **The Task:** Write out the conceptual code (or a detailed list of requirements) for a `<BaseButton>` component.

3. **What it needs:** It must accept three Props:
  
  1. `text` (What the button says).
  2. `color` (The background color of the button).
  3. `action` (The function that runs when clicked).
