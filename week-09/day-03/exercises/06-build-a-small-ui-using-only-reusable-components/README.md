# Build a Small UI Using Only Reusable Components

Course source: [Geeks Institute](https://www.geeks.institute/).
**The Mission:** You are building the **"System Health Panel"** for the AutoBarista dashboard. This panel lets the admin see if all the hardware is working.

**The Inventory:** You have already built these two reusable components:

1. `<Card title="..." >` (A white box with a title)

2. `<StatusRow deviceName="..." status="..." indicatorColor="..." />` (A single row of text with a colored dot next to it).

**Your Task:** Using *only* those two components, write the conceptual structure (like we did in Day 2) to build a UI that shows:

- A main box titled "Hardware Health".

- Inside that box, three rows:
  
  - "Dobot Arm" (Online, Green)
  - "Tuya Fingerbot" (Asleep, Yellow)
  - "Coffee Machine" (Offline, Red)
