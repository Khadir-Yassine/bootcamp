# Day 3: Building Reusable Components

[Day contents](README.md) · [Week overview](../README.md)

## Learning Summary

Build components with clear props and focused responsibilities. Practice reusable buttons, data passing and composing a small interface from reusable parts.

## Skills to Practice

- Design a clear component interface.
- Separate presentation and responsibilities.
- Reuse components without duplicating their implementation.
