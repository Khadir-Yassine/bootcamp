# Design Your Own Component Structure for a Simple App

Course source: [Geeks Institute](https://www.geeks.institute/).
**The Scenario:** Your team needs to build the **Client Mobile App**—the screen where a user actually presses a button to order their coffee from the robotic arm.

**The Requirements for the Screen:**

- It needs a welcome message showing the user's name.

- It needs a list of available drinks (Espresso, Americano, Latte).

- It needs a visual indicator showing if the robot arm is currently "Busy" or "Ready".

- It needs a big "Brew My Coffee" button.

**Your Task:** Write out the Component Tree for this screen. Show me who the Parent is, and who the Children are.

*Format it like this:*

- `<CoffeeOrderScreen>` (Parent)
  
  - `<UserWelcome ... />` (Child)
  - ... *(what goes here?)*
