# Split a Page into Reusable Components

Course source: [Geeks Institute](https://www.geeks.institute/).
1. **Objective:** Apply the bounding box method to your actual project.

2. **Instructions:** Look at the cover image we generated for your project. Focus *only* on the computer monitor showing the dashboard. Write down a list of every component you would need to build.

3. **Bonus:** Next to each component, write down what "Props" it might need to receive. (e.g., *Component: *`<DonutChart>` | Props needed: Percentage Value, Color Theme).
