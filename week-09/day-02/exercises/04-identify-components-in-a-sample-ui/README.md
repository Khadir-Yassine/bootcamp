# Identify Components in a Sample UI

Course source: [Geeks Institute](https://www.geeks.institute/).
1. **Objective:** Train your brain to stop seeing "pages" and start seeing "components."

2. **Instructions:** Go to YouTube. Take a screenshot of the homepage. Open it in Paint or any image editor and draw colored boxes over the UI.
  
  - Draw a RED box around the major layout regions (Header, Sidebar, Video Grid).
  - Draw a BLUE box around reusable child components (The Video Thumbnail card, the Search Bar, the Subscribe button).

3. **Takeaway:** Notice how the `VideoThumbnail` component is just copy-pasted 20 times with different "Props" (different image, different title).
