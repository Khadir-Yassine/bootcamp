# Day 4: Managing State and Interactions

[Day contents](README.md) · [Week overview](../README.md)

## Learning Summary

Distinguish state from props and connect clicks and inputs to state changes. Counter, toggle and task-list exercises turn display components into interactive features.

## Skills to Practice

- Identify where state should live.
- Update state from user events.
- Keep displayed values synchronized with application state.
