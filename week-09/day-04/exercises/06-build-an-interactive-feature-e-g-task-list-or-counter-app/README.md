# Build an Interactive Feature (e.g., Task List or Counter App)

Course source: [Geeks Institute](https://www.geeks.institute/).
**The Mission:** Forget the generic "Task List"—you are going to build the logic for the **AutoBarista Order Queue**. If three people order coffee at the same time, the system needs to remember them in a list.

**The Requirements:** You need to conceptually design an `<OrderQueue>` component.

1. **The State:** It needs a State variable that holds a list (array) of incoming orders.

2. **The Input:** It needs a button that says "Add Random Order". When clicked, it adds a new coffee to the State list.

3. **The Interaction:** Next to every order in the list, there is a "Mark as Served" button. When clicked, it removes that specific order from the State list.

**Your Task:** Describe how the State changes step-by-step when:

1. The dashboard loads.

2. The user clicks "Add Order" twice.

3. The user clicks "Mark as Served" on the first order.
