# Add State to a Component

Course source: [Geeks Institute](https://www.geeks.institute/).
- **The Goal:** Practice giving a component memory.

- **The Task:** Imagine you are building a `SessionBrewCounter` component for the admin dashboard. It keeps track of how many coffees were made *since the dashboard was opened*.

- **Action:** Write down what the State variable would be called (e.g., `brewCount`), what its starting value would be (e.g., `0`), and what event would cause it to increase (e.g., `onBrewComplete`).
