# Create Interactive Elements (e.g., Counter, Toggle)

Course source: [Geeks Institute](https://www.geeks.institute/).
1. **The Goal:** Practice handling user clicks.

2. **The Task:** The Robotic Arm needs a "Maintenance Mode" switch. If Maintenance Mode is ON, the arm will not accept new orders.

3. **Action:** Map out the logic. What is the State? What happens when the user clicks the toggle? What visual changes on the screen when the State flips from OFF to ON (maybe the background turns orange)?
