### **Exercise 1: Implement a Task Manager**

**Instructions**

**Objective:** Create a React task management system that allows different components to manage tasks using `useContext` and `useReducer`.

1. Set up a new React project using `create-react-app` or your preferred method.

2. Create a context for managing tasks.

3. Implement a task provider that includes a reducer for managing tasks.

4. Create components for adding tasks, displaying tasks, and removing tasks. These components should use the task context to interact with the task state.

5. Implement actions in the reducer for adding, completing, and removing tasks.

**Hints:**

- Each task can be represented as an object with properties like `id`, `text`, and `completed`.

- Use a unique `id` for each task to identify and remove them.
