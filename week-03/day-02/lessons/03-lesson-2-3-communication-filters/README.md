# Lesson 2.3 – Communication Filters

Course source: [Geeks Institute](https://www.geeks.institute/).
### Lesson 2.3 – Communication Filters

Humans do not communicate reality directly.
They filter it through their mind.

There are three main filters:

1. **Omissions** – leaving out details

2. **Generalizations** – using words like “always” or “never”

3. **Distortions** – misinterpreting intentions

Example:

- “They never respect deadlines” → Generalization

- “This is useless” → Distortion

Understanding filters helps reduce conflict and misunderstanding.
