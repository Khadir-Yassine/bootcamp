# Day 1: Advanced Javascript Functions

[Day contents](README.md) · [Week overview](../README.md)

## Learning Summary

Explore different function forms and more advanced JavaScript behavior. Understand the difference between copying primitive values and sharing references to objects.

## Skills to Practice

- Choose a suitable function form for a task.
- Trace changes made through object references.
- Organize transformations into reusable functions.

- II. Functions in JavaScript

- Functions
- Review on functions
- I. Nested functions
- II. Closures
- III. Currying
- Reference and primitive values: Pass by value, Pass by reference
- Mutability : Copying by reference
