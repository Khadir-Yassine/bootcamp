# Week 2 Learning Summary

[Week contents](README.md) · [All weeks](../CONTENTS.md)

## Weekly Focus

Develop stronger collection and object-processing skills, explore functions and classes, and connect forms to HTTP and JSON. Apply these ideas in searchable interfaces and small games.

## Day-by-Day Learning

### [Day 1: Advanced Javascript Functions](day-01/summary.md)

Explore different function forms and more advanced JavaScript behavior. Understand the difference between copying primitive values and sharing references to objects.

### [Day 2: Advanced Array methods](day-02/summary.md)

Transform, filter, search and aggregate collections with array methods and destructuring. Practice processing arrays of objects and choosing an appropriate method for each operation.

### [Day 3: Advanced Object Methods](day-03/summary.md)

Work with object methods, destructuring, copying, merging, classes and dates. Distinguish a shallow copy from an independent nested data structure.

### [Day 4: HTTP & Form method GET and POST](day-04/summary.md)

Connect form behavior to HTTP GET and POST, serialize data with JSON, and handle exceptions. Regular expressions and the Random Quote Generator provide additional practice with input and output.

### [Day 5: Mini-Project day](day-05/summary.md)

Build a searchable robot interface and a game using arrays, objects, functions and the DOM. The Anagram challenge adds focused string-processing practice.
