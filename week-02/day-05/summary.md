Build a searchable robot interface and a game using arrays, objects, functions and the DOM. The Anagram challenge adds focused string-processing practice.

## Skills to Practice

- Filter displayed information from a search input.
- Represent game state and implement game rules.
- Apply string transformations to compare words.
