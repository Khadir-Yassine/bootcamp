# Day 4: HTTP & Form method GET and POST

[Day contents](README.md) · [Week overview](../README.md)

## Learning Summary

Connect form behavior to HTTP GET and POST, serialize data with JSON, and handle exceptions. Regular expressions and the Random Quote Generator provide additional practice with input and output.

## Skills to Practice

- Explain how form data is sent with GET or POST.
- Convert between JavaScript values and JSON.
- Handle errors and validate structured input.
