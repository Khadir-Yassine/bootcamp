# Day 3: Advanced Object Methods

[Day contents](README.md) · [Week overview](../README.md)

## Learning Summary

Work with object methods, destructuring, copying, merging, classes and dates. Distinguish a shallow copy from an independent nested data structure.

## Skills to Practice

- Inspect keys, values and entries.
- Copy and merge object properties deliberately.
- Model structured information with objects and classes.

## Concepts Covered

- I. Methods of the Object constructor
- II. Object Destructuring
- III. How to copy an object : Cloning and merging, Object.assign
- Objects
- Classes
