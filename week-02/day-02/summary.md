# Day 2: Advanced Array methods

[Day contents](README.md) · [Week overview](../README.md)

## Learning Summary

Transform, filter, search and aggregate collections with array methods and destructuring. Practice processing arrays of objects and choosing an appropriate method for each operation.

## Skills to Practice

- Use map, filter and reduce for distinct operations.
- Extract values with destructuring.
- Process structured data without unnecessary repeated loops.

## Concepts Covered

- Description :
- Array forEach Method
- Array some Method
- Array every method
- Array map : Transforming
- Array filter : Filtering
- Array reduce
- Destructuring assignment
- Cloning Arrays
